# Project 42 Canonical Content

This repository contains the canonical open-source curriculum, knowledge checks, diagrams, and instructional packages for **Project 42**.

## License

All content, curriculum, diagrams, and training assets in this repository are licensed under the **[Creative Commons Attribution 4.0 International (CC BY 4.0)](LICENSE.md)** license.

## Structure

- `catalog.json`: Top-level index of learning paths, provider definitions, and badges.
- `modules/`: Individual modular curriculum units with objectives, sections, and knowledge checks.
- `diagrams/`: Canonical Mermaid sources (`.mmd`), validated SVGs, and diagram catalogue.
- `resources/`: Provider tools, comparison matrixes, and external learning references.
